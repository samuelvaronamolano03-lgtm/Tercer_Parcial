# Aprendizajes del curso 🚀

## Lo que aprendi

- [x] Crear repositorios con git init
- [x] Hacer commits con git add y git commit
- [x] Subir cambios a GitHub con git push

## Resumen de comandos

| Comando | Para que sirve | Ejemplo |
| ------- | -------------- | ------- |
| git init | Crea el repositorio | git init |
| git add | Prepara los archivos | git add . |
| git commit | Guarda los cambios | git commit -m "mensaje" |
| git push | Sube a GitHub | git push origin main |

Aprendi mucho en este curso 🎉
